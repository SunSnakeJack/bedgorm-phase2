## พฤติกรรมที่เปลี่ยน

- การ์ดผลตาบอตอ่านบันทึกที่เปิดเผยอยู่แล้วและแสดงทีละรายการห่างกัน 1.8 วินาที บันทึกแต่ละ action ระบุลำดับตาและที่นั่งเพื่อให้แสดงครบเมื่อ polling ได้หลายตาพร้อมกัน การ์ดอยู่แยกจากสถานะตาปัจจุบันและไม่หน่วงการส่งคำสั่งหรือตัวจับเวลา
- หมาก 2–3 ตัวเยื้องกัน หมาก 4 ตัวขึ้นไปวางสองคอลัมน์พร้อมเลขลำดับ แตะช่องเพื่ออ่านชื่อ สี และลำดับจากบนลงล่าง แมวเดินย้อนมีขอบประและสัญลักษณ์ ↶
- มือถือมีแถบควบคุมติดขอบล่างพร้อมปุ่มทอยและหมวดอื่น เปิดตัวเลือกเท่าที่ต้องใช้ ย่อด้วยปุ่มในแถบหรือ Escape และย่อหลังส่ง action แถบแสดงสถานะรอตา กำลังส่ง และข้อผิดพลาดจากเซิร์ฟเวอร์

## ตรวจรับบน Staging

1. เล่นห้องออนไลน์ 2 คนกับ 2 บอต ตรวจชื่อและผลของบอตทั้งสองตามลำดับ และลองเล่นตาตัวเองทันทีที่ถึงตา
2. ที่ 360px และ 390px ตรวจว่ากระดานอยู่เหนือแถบเมื่อย่อ แตะเปิดทายรอบ วางไอเทม และทายลับ แล้วตรวจสถานะปุ่มก่อนและหลังส่ง
3. แตะช่องที่มีแมวซ้อน เทียบสีและลำดับกับตำแหน่งบนกระดาน ทดสอบการกู้ที่นั่งเดิมหลังรีเฟรช
4. ตรวจอีกครั้งบน iPhone Safari และ Android Chrome โดยเฉพาะ safe area, การขยายแถบ และ Reduce Motion
