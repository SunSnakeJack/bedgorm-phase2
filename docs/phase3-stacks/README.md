# Bedgorm Phase 3 — กองแมวซ้อนทับ

กองใหม่แสดงตัวหมากจากบนลงล่าง โดยตัวบนทับส่วนหนึ่งของตัวถัดไปและเยื้องด้านข้างเล็กน้อย ช่องที่มีแมวตั้งแต่สี่ตัวขึ้นไปแสดงหมากสามตัวบนสุดพร้อมป้ายจำนวนรวม เมื่อแตะช่องจะแสดงชื่อ สี และลำดับจริงของทุกตัว รวมถึงสถานะแมวเดินย้อน

ภาพก่อนปรับใช้ `f121a67` ภาพหลังปรับใช้ข้อมูลทดสอบชุดเดียวกัน ความสูง viewport 640px ช่อง 3 เป็นกองที่เปรียบเทียบ
